# 行为准则 / Code of Conduct

请尊重所有参与者，讨论问题时聚焦事实和建设性反馈，不容忍骚扰、歧视或泄露他人隐私。维护者可移除不符合本准则的内容。

Treat everyone with respect. Keep discussion factual and constructive; harassment, discrimination and disclosure of others' private information are unacceptable. Maintainers may remove content that violates these expectations.
