# 安全说明 / Security

当前版本仅供学习，尚未完成生产环境安全审计，已知密码以明文处理。请勿在公开 Issue 中发布漏洞细节、凭据或个人数据；请通过 GitHub 仓库的私密漏洞报告功能联系维护者（如该功能可用）。

The current version is for learning and has not undergone a production security audit; passwords are handled in plaintext. Do not post vulnerability details, credentials or personal information in public issues. Contact the maintainer using GitHub private vulnerability reporting if enabled.
