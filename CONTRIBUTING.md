# 贡献指南 / Contributing

欢迎通过 Issue 描述问题或建议。提交 Pull Request 前请说明变更目的，保持改动集中，运行 `dotnet build ClubHub.sln` 并注明测试环境和未验证的功能。不要提交密码、个人信息、数据库导出或本地配置。

Issues and pull requests are welcome. Describe the purpose of a change, keep it focused, run `dotnet build ClubHub.sln`, and note the environment and untested behavior. Never commit passwords, personal information, database dumps or local configuration.

参与项目即表示同意遵守 [行为准则](CODE_OF_CONDUCT.md)。 / Participation is subject to the [Code of Conduct](CODE_OF_CONDUCT.md).
