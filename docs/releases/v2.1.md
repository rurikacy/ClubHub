# ClubHub v2.1

## 中文

ClubHub 是一个基于 ASP.NET Core 的校园社团管理项目，面向社团日常管理和学习交流。

### 主要功能

- 管理社团、部门、成员及入社申请。
- 发布活动，支持报名、签到，以及对未达到最低人数要求的活动进行自动取消检查。
- 通过 SignalR 进行社团内实时讨论，并发布消息和公告。
- 创建问卷、收集回答并查看统计结果。

### 使用说明

源码包含 SQL Server 表结构和菜单数据，**不包含原始账号及业务记录**。运行前需要自行配置数据库连接和账号；详细步骤请参阅仓库中的中文 README。

### 已知限制

- 当前版本以明文处理密码，部分管理界面也会显示密码，仅建议在隔离的学习环境中使用。
- 数据库初始化和完整功能尚未在全新环境中验证；部分代码引用的表不在现有数据库导出中。
- 部分类库和依赖较旧，存在已知安全问题。现有 Dockerfile 与 Web 项目的 .NET 8 目标不匹配，尚未验证可用。

## English

ClubHub is an ASP.NET Core campus club management project for day-to-day club administration and learning.

### Features

- Manage clubs, departments, members, and membership applications.
- Publish activities, handle registration and check-in, and automatically check whether activities meet their minimum participation requirements.
- Hold live club discussions with SignalR and publish messages and announcements.
- Create surveys, collect answers, and view statistics.

### Getting Started

The source includes the SQL Server schema and menu data, but **does not include the original accounts or business records**. Configure a database connection and create an account before use. See the English README in the repository for setup instructions.

### Known Limitations

- This version handles passwords in plaintext, and some management screens display them. It is intended for isolated learning environments only.
- Database initialization and full functionality have not been verified in a fresh environment. Some tables referenced by the code are missing from the existing database export.
- Some libraries and dependencies are old and have known security issues. The current Dockerfile does not match the web project's .NET 8 target and has not been validated.
